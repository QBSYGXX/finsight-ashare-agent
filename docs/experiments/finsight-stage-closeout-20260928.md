# FinSight 金融财报 Agent 阶段收尾报告

记录日期：2026-09-28。阶段交付版本：v0.15.5。状态：**当前阶段收尾，进入限定范围试用；保留已知问题，暂不重新微调。**

## 1. 交付结论

FinSight 已形成可运行、可追溯的财报问答流程：用户提出问题，基础模型登记任务并调用工具，RAG 提供财报原文，财务工具查询已核验事实并计算，程序检查结果和引用，最后保存执行轨迹与评测产物。

作为第一个大模型与 Agent 实战项目，本阶段已经覆盖数据准备、RAG、模型推理、工具编排、财务计算、证据核验、评测和版本管理，可以用于现有数据与指标范围内的查询、演示和学习。收尾不以诊断集满分为条件，也不再默认通过连续发布补丁来扩展范围。

最新结果：原诊断 **12/13**；自然问法诊断 **24/28**，其中需要调用模型的题目 **20/24（83.3%）**，前置检查 **4/4**。这些题目已经用于开发诊断，不能当作独立测试集准确率。比亚迪、迈瑞医疗的独立测试仍未用于本轮评测。

本报告接受当前版本作为阶段交付，未宣称开放财报问答、任意指标、自动投资研究或生产服务已经验收。后续独立测试和微调属于可单独立项的下一阶段，不作为本次继续修改代码的前提。

## 2. 当前系统及使用范围

| 层次 | 当前实现 | 责任与边界 |
|---|---|---|
| 数据 | 全项目36份年度报告、216条已核验事实；原文页文本保留来源信息 | 已核验数值与普通原文分开，不把检索到的任意数字直接当作已核验事实 |
| 财报 RAG | 按页切块，BM25 与 BGE-M3 向量检索，经 RRF 融合 | 找相关原文，保留公司、报告年度、页码、片段位置与来源哈希 |
| 模型 | 基础 Qwen3.5-9B，vLLM＋MTP；本轮 thinking off | 选择查询目标、工具和证据；当前未加载旧 LoRA |
| Agent | 计划登记、检索、读页、财务指标、结束动作；每题最多10步 | 根据工具反馈继续执行，记录失败和重试；仍可能理解错任务 |
| 财务工具 | 登记公式、依赖字段、Decimal 运算、单位和口径校验 | 数值来自已核验事实；缺失字段不以邻近指标替代 |
| 引用与输出 | 原文选句、坐标恢复、数值来源记录、JSON/HTML产物 | 引用存在可核验；相关性和回答完整性仍需要评测或人工复核 |
| 评测 | 原13题＋自然28题、前置边界、逐题轨迹及哈希导出 | 将程序测试、参考轨迹回放、真实模型成绩分别报告 |

当前已实测的混合检索索引为验证公司中兴通讯、美的集团的6份年度报告，包含1,639页、7,006个片段；每块512字符、重叠80字符。不能把全项目36份报告误写成此次全部已评测。

典型执行路径：

```text
用户完整问题
  → 公司、年度、报表口径与期间检查
  → 模型登记目标并选择工具
      → 文字问题：检索 → 读页 → 选取原句
      → 数值问题：已核验事实 → 公式与口径校验 → 计算
  → 程序汇集结果、核验来源
  → 回答与执行轨迹
```

适合现阶段使用的任务包括年度财务指标、部分多年度/多指标查询、年报风险措施原文摘录，以及数值与原文组合查询。季度/半年数据、未登记指标、自动补全缺失字段、自由撰写长篇投资分析和多轮省略上下文不在本阶段交付范围内。同比能力存在明确缺陷，见第5节。

## 3. 本阶段主要改动

最近的工作主要改进模型周围的系统，而非修改模型权重：

1. **推理加速。** 建立无需管理员权限的离线独立环境，验证 vLLM 和 MTP 的吞吐收益。
2. **RAG 与财务工具整合。** 财报原文用于文字证据，结构化事实与登记公式用于数值计算，两条路径在同一 Agent 内协作。
3. **执行协议修复。** 处理无歧义动作格式、冗余引用参数、状态变化后重试以及任务结束时结果汇集。
4. **引用细化。** 从整段搬运转为选择已观察原文的句子，程序恢复原文和坐标。
5. **评测建设。** 固定自然问法、参考结果和评分，保留历次真实成绩，区分缺失数据、参数错误、规划错误和评分代理局限。

v0.15.5 没有改动冻结训练数据、财务事实、两套评分、指标公式或推理环境。本次服务器轨迹没有触发动作外层格式规范化，不能把成绩提高直接归因于该转换器；提示词和重试逻辑也发生了变化，未做逐项消融。

预设检索词的目标页命中@6为原组5/5、自然组6/6，与上一版相同。主题存在复用，这不是模型自主生成检索词的独立召回率，也不是整个知识库的检索准确率。

本次结果核验已完成：ZIP CRC、无重复成员、准确成员清单、50项内部文件哈希、外部SHA256、23项本地源码与导出清单对应；冻结自然题参考未变，依赖和索引清单与上一版一致。此前对该返回包的逐题核验已独立重算全部41条评分，与导出记录一致；12处最终引文与本地来源文字及坐标一致，36条返回财务来源记录的返回字段与本地事实一致。报告落盘前再次复核包哈希、文件清单、源码指纹、冻结参考及分组汇总。

这些来源检查验证的是本地归档证据链，不是重新下载并审计全部原始PDF，也不等于引用内容完整覆盖了问题。发布前67项本地测试通过的记录保留在版本报告中；本次仅新增文档，没有重新运行模型或训练。

### 速度结果

本次第一道模型题218.470秒，包含冷启动；其余33道模型题1.340—19.817秒，中位数5.817秒。上一版对应中位数为4.391秒。本次生成调用的输入token中位数从1,496.5增至3,015，记录的生成吞吐中位数从86.843降至62.483 token/s；该指标含输入处理时间，不是纯解码速度。

调用与错误次数减少，没有转化为本轮更短的中位响应时间。提示上下文变长与这一变化同时发生，未通过控制变量实验确认全部因果。

此前v0.13固定负载实验中，Transformers、vLLM、vLLM＋MTP的中位吞吐分别为23.31、82.20、118.17 token/s，相对原环境为1、3.53、5.07倍。该实验采用同一卡、同一提示词、预热后固定512token、每组3次，包含prefill但不含启动；不能把该倍数直接套用到当前不同上下文、多个工具步骤的端到端延迟。完整方法见[推理加速报告](vllm-v013-inference-audit-20260927.md)。

以上问题在限定范围试用时披露并保留，本阶段不继续发补丁。后续若发现错误金额被当作成功结果输出、来源无法复核或口径被静默替换，再单独立项修复；现有样本通过核验不保证未来每道问题都正确。

## 6. 微调结论

**当前不重新微调。** 现阶段没有证据表明重训是完成项目的必要条件，也未做能把当前缺陷单独归因于模型权重的实验。

早期LoRA训练已经完成，主要学习当时“检索—读表—计算”的工具调用协议。最近的Agent采用新的任务登记、财务指标、选句和结束接口，当前评测明确使用基础模型，没有加载旧LoRA。旧模板验证的高分与当前自然问法诊断不属于同一实验，不能直接比较或宣传为微调收益。

后续若希望补齐“微调是否有效”的学习实验，应以本阶段冻结系统为基线：准备适配当前接口、经工具执行核验的训练轨迹，包含正确调用、缺失处理、同比澄清和失败恢复；在相同检索、工具、提示词与推理预算下比较基础模型和新LoRA。两版本及评测方案确定后，再使用独立测试公司，不围绕测试题追加训练。收益与退化都应保留。

该实验、更多财报/指标、Web界面和复杂多轮对话均是下一阶段可选工作，本报告不启动这些任务。

```bash
cd /calc/users/geyuboao/workspace/FinSight
bash agent_v015/run.sh chat --split validation --retrieval hybrid --backend vllm-mtp --thinking off
```

每题提供完整公司、年度和指标；当前不继承上一题上下文。默认验证范围是中兴通讯、美的集团。输入`exit`退出。可直接试用：

- 中兴通讯2024年毛利率是多少？

- 中兴通讯2024年年报对客户信用风险采取了哪些管理措施？请摘录原文。
- 给出中兴通讯2024年的资产负债率，再引用年报中防范客户信用风险的措施。

状态解释：`partial`表示只有部分目标成功；`no_results`需结合字段、年度或口径说明理解；`needs_clarification`需要补充信息；`step_limit`表示流程未完成，不表示公司没有披露数据。即便是`completed`，仍需检查目标是否遗漏、引用是否相关。

```bash

bash agent_v015/run.sh evaluate --suite all --export-after
```

正常退出不等于全部题目通过。分别查看两组`summary.json`、逐题JSON和`report.html`，按打印的`EXPORT`下载结果及SHA256文件。本阶段收尾不要求再次运行这套实验。
