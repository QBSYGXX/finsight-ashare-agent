## 未完成与限制

本次是完整主线的第一阶段可运行实现，不是所有功能完成：叙述答案采用原文摘录，尚未提供自由综合论述；财务字段仍限于现有216条已核验事实；没有OCR/任意表格自动审核；多公司对比与多轮省略问法暂不支持；没有Web服务与新协议LoRA。

`completed`仅表示动作协议与来源核验完成。引用存在不等于语义相关或完整回答，因此固定诊断题额外检查数值、单位、预期缺失状态、目标页和关键词，并保留人工评阅空间。13题包含3题前置拦截，不能称为13题模型问答准确率。

下一关是在服务器运行 `doctor → index → ask/evaluate`。以取回的真实轨迹判断模型是否正确选工具和选证据，再补充参考答案、冻结新协议，决定下一轮LoRA训练目标。比亚迪、迈瑞不在本轮索引/诊断中。
