# 财报事实如何核对

原始PDF位于 `data/raw/公司代码-报告年份.pdf`。下载清单位于 `data/manifest.json`，保存官方URL、标题、SHA256。遇到多个修订版本时，自动获取会停止，让研究者明确选择；不悄悄用另一个年份的报告代替。

`prepare --stage ingest` 提取逐页文本并生成 `data/audit.csv`。候选可能抓到管理层讨论、流动负债合计或母公司表，需要调整；value和unit故意留空。长表断行、扫描PDF、单位跨页和重述均不能仅凭“抽到一个数字”通过审计。

逐行填写：

| 字段 | 含义 |
| --- | --- |
| report_id | 来源报告，例如600519-2024 |
| year | 数字所属会计年度，不一定等于来源报告年份 |
| metric | revenue营业收入、cost营业成本、net_profit归母净利润、operating_cashflow经营现金流净额、assets总资产、liabilities总负债 |
| value | 原始数值，允许千分位；不要先换算为亿元 |
| unit | 元、万元或亿元；本版以人民币数据为范围 |
| scope | consolidated；只接受合并口径核验事实 |
| page | PDF物理页码，从1开始，不是查看器显示的自定义页签 |
| evidence | 该页的原文短摘录，包含完整数字；空白差异会被规范化 |
| reviewer | 实际核对者/核对方式；AI核对应如实标注 |
| status | pending或approved；核对全部字段后才批准 |

检查项目、年度列、人民币单位、合并表标题以及是否存在重述。同一公司、年度、项目只能有一个最终核验口径；如果选用次年报告的重述比较列，应对相关比较数据保持一致，并在研究记录注明。自动校验能检查页码、原文、数值token和PDF哈希，无法代替判断数字是否属于正确年度列。

特别注意：营业收入不一定等于营业总收入；归母净利润不等于全部净利润；流动负债合计不等于负债合计。毛利率使用(营业收入-营业成本)/营业收入；“归母净利润/营业收入”明确命名，不冒充普通净利率。上年为零或负数时不输出常规同比百分比。

可用脚本导出指定页，原PDF不改变：

```bash
python scripts/inspect_pdf.py data/raw/600519-2024.pdf --pages 58 59 60 63 64
```

种子样例提供12条经过Codex图像和文本交叉检查的事实，包含2023、2024年度，但只来自2024年报告。它不代表12家公司36份年报已全部核验。

完整训练需要12家公司 × 3年度 × 6指标的覆盖，共216个公司-年度-指标单元。训练与验证/测试按公司隔离，不随机拆同一公司的类似问题。约800条轨迹由这些事实执行构造，单位变体共享底层数据；训练样本数不等于独立原始事实数。每条训练轨迹重放工具，并用实际Qwen模板数token；超4096会剔除并记录原因。

首版题型包括读取、单位换算、同比增减/增长、毛利率/负债率/现金利润比和缺失母公司口径；它主要衡量固定财报任务内的工具使用与证据可靠性，不证明开放金融推理或投资预测能力。自动评测核对结构化结果，无法证明答案每句自然语言都正确。
