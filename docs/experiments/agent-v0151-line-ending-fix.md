# v0.15.1：跨平台事实文件校验修复

2026-09-28，服务器v0.15在doctor阶段报 `文件校验失败：data/verified/facts.json`，EXIT=1。后续index/ask因命令链中断而未启动。

本机核对发现，打包程序错误地将Windows事实文件的原始字节哈希作为跨平台唯一标识：

- 本机事实文件有5618个CRLF，原始SHA256为 `48e6796f4bc66ceae4871345d13cc64e871b5e68cb0b40e44ac00775ee294962`。
- 仅改为LF后为 `d30dd46f31a197afafbc4bc68fef9e85c97189b86ca0faad1544e485122251b5`。
- 本机216条事实的JSON内容摘要为 `e61b108930255d80a6017b92043e1ae02d25acf6ab9392c656598f2a4f824c4d`，与此前发布的v0.13内容校验协议一致。
- `data/manifest.json`也有327个CRLF，因此同样需要兼容。其他四项依赖无CRLF，源码与此前v0.13上传包字节相同。

当前服务器文件的实际哈希尚未取回，所以不能只凭这条报错认定服务器一定仅有换行差异。修复允许且仅允许这两个JSON文件的物理CRLF/LF差异；不改JSON字段、值、顺序或内部转义字符串，不重写原始数据，不更新旧冻结清单，也不放宽源码校验。若还有内容差异，修复版继续拒绝运行，并打印原始及LF摘要用于定位。

25项测试通过：原有19项加6项换行兼容/篡改拒绝测试，覆盖修改金额、字段名、证据文字、字符串中的转义换行和源码换行。服务器doctor、建索引和模型运行仍须由真实输出验收。

新上传包 `finsight-agent-v0.15.1.zip` 仅包含 `agent_v015/`，旧v0.15上传包保留；更新无需重装环境和模型。
