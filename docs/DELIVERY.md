## 现在如何演示

现有离线服务器已经部署，无需重装或重训。登录后执行：

```bash
cd /calc/users/geyuboao/workspace/FinSight
bash agent_v015/run.sh doctor
```

诊断无阻断错误、GPU可用后，再执行：

```bash
FINSIGHT_GPU=1 bash agent_v015/run.sh chat --split validation --retrieval hybrid --backend vllm-mtp --thinking off
```

默认使用基础Qwen3.5-9B；不是新LoRA。一次加载后可连续提问，输入`exit`退出。每题应写明公司、年度和指标，不依赖上一轮省略信息。可依次演示：

1. `中兴通讯2024年毛利率和资产负债率是多少？`
2. `中兴通讯2024年年报对客户信用风险采取了哪些管理措施？`
3. `中兴通讯2024年上半年营业收入是多少？`（展示不支持期间的明确返回）

第三题被拒绝是范围检查，不代表公司没有披露。默认验证索引只支持中兴和美的；其余训练公司索引构建方式见[Agent历史说明](../agent_v015/README.md)，本次不扩大演示范围。

程序打印`RUN`、`TRACE`和日志路径。问答位于`outputs/agent_v015/runs/<RUN>/question-N.json`及同名HTML，可直接下载HTML在本机打开。也可将本次实际RUN替换进命令：

```bash
bash agent_v015/run.sh export --run '实际RUN值'
```

下载输出的ZIP和SHA256。命令退出正常只表示执行结束，回答是否完成看单题状态。没有服务器时可直接打开[离线报告](../examples/research_v1/report.html)；它是已完成实验的静态摘录，不是本地实时模型演示。

## 源码包与新机器复现

源码包来自Git已提交文件，附`SOURCE_MANIFEST.json`记录提交号及逐文件SHA256。保留GPL-3.0和上游出处；包外同名`.sha256`使用LF换行。源码包**不是覆盖现有服务器的升级补丁**，也不是包含环境与模型的一键安装包。

仅阅读与CPU测试：Python 3.11+，安装pytest后，在解压的项目根目录执行：

```bash
python -m pytest agent_v015 -q
python -m pytest lora_v0161 -q -k "not corpus_frozen_and_train_only and not training_data_and_recipe_unchanged"
```

第二条排除两项依赖未分发训练文本的测试；没有固定Transformers wheel时有6项兼容性检查按代码约定跳过。它们不构成GPU训练验证。实际源码包检查结果见[发布验证](RELEASE_VALIDATION.md)。
