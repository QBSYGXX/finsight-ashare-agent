# 当前协议真实运行案例

双击[report.html](report.html)可离线查看，或阅读[cases.json](cases.json)。不加载模型，不要求服务器。

三个案例来自2026-09-29同轮LoRA对照的已核验返回包：

- M01/base：中兴通讯2024年毛利率37.9127%、资产负债率64.7361%，含公式与原始事实来源。
- R02/base：客户信用风险管理措施，选取PDF第45页的真实原句。
- R02/tuned：同一问题错误拒答，说明新LoRA没有全面超过基础模型。

这些是选定记录的精简展示，不是实时问答，不是盲测。未复制完整日志或整份PDF。JSON保留原成员哈希、结果、少量公开来源摘录与动作；省去中间检索全文和生成器元数据。完整核验说明见[报告](../../docs/experiments/lora-v0161-result-audit-20260930.md)。

复现提取：在项目根目录运行`python scripts/build_closeout_examples.py <已核验的结果ZIP路径>`。脚本先校验固定ZIP哈希，拒绝使用不同结果包。
