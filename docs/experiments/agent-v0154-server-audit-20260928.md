## 失败分类

- M01、N07、N11、N26：连续10次使用`{"plan":{...}}`外层结构，被严格双键解析器拒绝。各轮prompt哈希不同，不能归咎于返回了同一缓存。N07还把百分点变化拆成两年value；N26还擅自将含糊同比选为增长率，所以修格式并不能证明这两题会通过。

- N08：只登记经营现金流和归母净利润；随后尝试计算其比率，被锁定目标机制拒绝，最终仅返回两个金额。
