**Research v1.0已阶段收尾。** [交付与运行说明](docs/DELIVERY.md) · [无需GPU的真实案例](examples/research_v1/README.md) · [代码阅读顺序](docs/READ_THE_CODE.md) · [源码发布验证](docs/RELEASE_VALIDATION.md)

基于开源 FinSight 思路与 Qwen3.5-9B 的年度财报研究项目，将财报原文检索、模型工具调用、可核验财务计算和证据引用连接起来，并研究协议对齐的 LoRA 与推理加速。

**2026-09-30阶段收尾：v0.15.5可用基线、新协议LoRA训练与配对评测、vLLM/MTP测速均已完成。** 现有交互入口继续使用基础模型；新LoRA改善了诊断集上的规划，但也出现原文任务退化，保留为独立实验，不自动替换默认模型。此后不以诊断集满分为交付条件。

## 可以做什么

- 查询已覆盖年度与公司范围内的登记财务指标，支持部分多年份、多指标及同比任务。
- 检索年报风险及管理措施，返回原文摘录、页码和来源。
- 在同一个问题中组合数值查询与原文证据；保存逐步动作、错误、来源及JSON/HTML记录。
- 对缺字段、报表口径不一致、未支持期间等情况返回明确状态。

当前属于“原文摘录＋确定性指标”的受限研究助手。季度/半年数据、任意指标自动补全、多公司比较、多轮省略上下文及自由撰写长篇投资分析，不属于本阶段验收范围。引用存在不等于相关性或回答完整性自动成立。

## 工作流程

```text
用户问题 → 公司/年度/口径检查 → 模型登记查询目标
  ↔ report_search：BM25 + BGE-M3检索，RRF融合
  ↔ read_page：展开已检索的原文页
  ↔ financial_metric：已核验事实 + 登记公式 + Decimal运算
  → finish：选择已观察原句，汇集已检查指标结果
  → 引用/单位/口径检查 → 答案和执行轨迹
```

模型决定动作，工具反馈再进入下一轮上下文，最多10步。财务数字由工具计算；模型不自行填入未经核验的数字。基础模型和LoRA模型使用同一工具协议进行对照。

## 数据与已完成实验

全项目归档12家公司2023—2025年共36份年度报告、216条已核验事实，按8家训练、2家验证、2家独立测试隔离。本轮实际检索与评测索引为中兴通讯、美的集团的6份年报、1,639页和7,006个片段；不能将全部36份报告写成本轮均已评测。

当前协议LoRA使用690条执行过的规则教师轨迹、2,273个下一动作样本；仅当前JSON动作及EOS计算损失。实际使用单张A800 80GB，BF16、rank16、有效batch32、2轮144步，正式训练约6小时3分钟；服务器重载及保留MTP的权重合并通过。

| 2026-09-29同轮配对诊断 | 基础模型 | 新LoRA合并模型 |
|---|---:|---:|
| 原诊断 | 12/13 | 12/13 |
| 自然问法 | 24/28 | 27/28 |
| 自然问法模型题 | 20/24 | 23/24 |
| 两组累计模型调用 | 179 | 129 |
| 两组累计错误动作 | 26 | 4 |

这些是开发诊断、单种子成绩，不是独立测试或开放财报问答准确率。N26的通过包含拒答，不代表主动追问；R02原文问题出现拒答退化；N13两组均被评分判失败，但新模型从相关摘录退化为步骤上限。全部保留在[逐题核验报告](docs/experiments/lora-v0161-result-audit-20260930.md)。

独立的v0.13固定负载实验：同一A800、同一思考提示词，预热后512token、每组3次，中位生成吞吐为23.31（Transformers）、82.20（vLLM）、118.17（vLLM＋MTP）token/s。包含prefill、不含加载，且新环境同时升级Torch/CUDA；5.07倍不能直接套用到多步Agent端到端延迟。

## 现有服务器上的推荐入口

以下命令依赖已经部署的模型、数据、validation-hybrid索引及离线环境。不是全新机器仅克隆源码即可运行的承诺。在服务器项目根目录执行：

```bash
bash agent_v015/run.sh doctor
bash agent_v015/run.sh chat --split validation --retrieval hybrid --backend vllm-mtp --thinking off
```

可试问：`中兴通讯2024年毛利率和资产负债率是多少？` 或 `中兴通讯2024年年报如何描述汇率风险及应对措施？`。

完整操作见[Agent说明](agent_v015/README.md)。该说明部分段落保留发布时历史状态，当前验收结论以本首页和阶段报告为准。新LoRA通过独立评测入口加载，现有chat命令不会自动加载新权重。

新机器复现还需准备模型快照、财报/核验事实及索引：[便携环境](docs/PORTABLE_ENV.md)、[vLLM离线环境](vllm_v013/README.md)、[数据方案](docs/FORMAL_DATA_V04.md)、[LoRA流程](lora_v0161/README.md)。模型、原始财报、运行环境和LoRA权重不随Git源码分发。
