## 实现

新模块`action_contract.py`负责外层格式规范化和动作重试判定。仅接受无歧义单工具简写并展开为标准双键结构；原始模型输出仍在轨迹，转换记入`action_normalization`。JSON重复键、多工具和未知工具拒绝。所有参数仍通过原有公司/年度/指标/来源约束。

`finish`同时携带selections和同源evidence_ids时，只移除被选句覆盖的冗余整段指定；不同ID不自动合并或丢弃，越界/非整数编号继续拒绝。主提示词只推荐selections，纯数字题空列表，减少接口选择歧义。

成功动作单独记账，避免重复读相同数据。失败动作按“动作 + 当前计划、已检查结果和已观察证据ID”记账：状态有变化才允许重试。N01先finish缺结果、随后读完收入成本，再次finish应能结束；只有动作相同不足以判断它无效。状态指纹写入轨迹。

提示词从生产目录提供全部指标的已有公式和别名，增加一般性目标规划说明及合法JSON动作示例。问比例应登记比率目标；问同比应登记相应transform，上年输入由工具处理；不得把计算依赖冒充用户目标。没有把冻结题目、数值或评分结果提供给模型，也没有按题目ID自动纠正计划。

这是应用层兼容和提示词修复，不是token级约束解码。vLLM适配器、推理预算和环境不改；实际问答改善仍需服务器实跑，不能预告通过率。
