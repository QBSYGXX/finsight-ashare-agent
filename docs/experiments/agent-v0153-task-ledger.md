## v0.15.3做了什么

增加模型先登记的任务清单：只含用户请求的metric/year/transform及是否需要叙述证据。清单登记后不能临时改变目标；计算依赖继续由财务引擎处理。`financial_metric`拒绝清单外的替代指标，并返回已检查/待检查状态。缺失是这个目标的合法结果，不等于公司未披露。

`finish`由程序汇集全部已检查目标，包含成功和缺失；模型不用再维护结果ID列表。未执行的目标会阻止完成；混合问题缺少叙述证据时仍不能宣称完整成功。清单由模型生成，程序不能证明其语义完整性，因此仍保留`completeness_verified=false`，评分对照原题需求。

已观察的财务事实ID可以作为引用，正文从经过计算工具读取的原始事实中获取。未观察的事实ID仍拒绝。纯数值问题中，RAG原文片段只保存在轨迹，不用于填补缺失数字；避免把合并口径原文当作母公司答案。显式scope参数仅在与用户口径一致时接受，不能切换口径。

已有索引、嵌入模型、事实库、财务公式、推理模型/预算不变。评测问题和评分文件保持逐字节不变。新轨迹协议标识为`agent-v015.3`。
